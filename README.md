# 涨停复盘数据处理工具

这是一个专门用于处理股票涨停板数据的工具系统，可以对涨停股票数据进行分析、分类和分页导出。系统提供Web界面和命令行两种使用方式。

## 功能特点

1. **Excel 数据处理**：自动解析包含涨停板股票信息的 Excel 文件
2. **智能分类**：根据"涨停原因"对股票进行分类整理
3. **优化排序**：
   - 首先按照"连续涨停天数"降序排列
   - 再按照"最终涨停时间"升序排列
4. **自适应分页**：根据设定的约束条件自动分页，确保每页内容合理分布
5. **多种输出格式**：
   - 分页 Excel 文件
   - 涨停原因统计 CSV 文件
6. **Web 界面**：提供友好的网页操作界面
7. **命令行接口**：支持命令行批处理操作
8. **子表字段合并**：支持将相关子表数据合并至主表，合并后字段以"子表value"格式命名并在分页结果中显示

## 技术栈

- Node.js
- Express.js (Web 服务器框架)
- SheetJS (Excel 处理库)
- Multer (文件上传中间件)
- HTML/CSS/JavaScript (前端界面)

## 安装与部署

### 环境要求

- Node.js (版本 12 或更高)
- npm (Node.js 包管理器)

### 安装步骤

1. 克隆或下载项目代码到本地目录

2. 安装项目依赖：
   ```bash
   npm install
   ```

3. 启动 Web 服务：
   ```bash
   node server.js
   ```

4. 在浏览器中访问 `http://localhost:3000` 使用 Web 界面

### 命令行使用方法

除了 Web 界面外，还可以直接使用命令行工具处理 Excel 文件：

```bash
node process_excel_cli.js <输入文件路径> [输出目录]
```

例如：
```bash
node process_excel_cli.js ./data/今日涨停非ST-20251119.xlsx ./output/
```

执行成功后将在输出目录生成：
- 按规则分页的 Excel 文件（每页一个文件）
- 涨停原因统计 CSV 文件

## Web 界面使用说明

1. 打开浏览器访问 `http://localhost:3000`
2. 点击上传区域选择要处理的 Excel 文件
3. 可选：调整分页约束值（默认为33）
4. 点击"处理文件"按钮开始处理
5. 处理完成后可预览结果并下载分页文件

## 数据处理规则

1. **关键字段识别**：
   - 最终涨停时间
   - 连续涨停天数(天)
   - 涨停原因
   - 涨停原因类别

2. **排序规则**：
   - 首先按"连续涨停天数"降序排列（天数多的在前）
   - 然后按"最终涨停时间"升序排列（时间早的在前）

3. **分页规则**：
   - 按"涨停原因"分类优先排列
   - 使用公式 `分类数 × 2 + 条目数 ≤ 约束值` 控制每页内容量
   - 默认约束值为33，可在Web界面或CLI参数中调整

4. **子表字段合并**：
   - 支持将相关子表数据合并至主表
   - 合并后的字段按"子表value"格式命名
   - 分页逻辑作用于合并后的数据结果
   - 分页表格中包含"子表value"字段的显示

5. **特殊处理**：
   - 自动清理列名中的日期后缀
   - 规范化"涨停原因类别"字段格式
   - 将"其他概念"类别始终排在最后

## 注意事项

1. 上传的 Excel 文件需要包含指定的关键字段列
2. Web 界面处理完成后临时文件会被自动清理
3. 分页算法会尽量保持同类别的数据在同一页面，但大量数据时可能会出现跨页情况
